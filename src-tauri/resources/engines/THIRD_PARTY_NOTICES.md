# Bundled engine notices

Nice Downloader release packages may contain the following independently
developed command-line programs. Nice Downloader invokes them as separate
processes and does not claim ownership of them.

- yt-dlp — ISC License; <https://github.com/yt-dlp/yt-dlp>
- gallery-dl — GNU General Public License version 2; <https://github.com/mikf/gallery-dl>
- FFmpeg and ffprobe — GNU General Public License version 3 for the currently
  pinned builds; <https://ffmpeg.org/>

The exact versions, distribution URLs, and SHA-256 digests are recorded in the
repository's `engines.lock.json`. Release maintainers must include the complete
upstream license texts and satisfy corresponding-source obligations before
publishing packages. This summary is not a replacement for those license texts.
